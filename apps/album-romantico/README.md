# album-romantico

Album visual romantico con galeria de fotos, detalles y modo slideshow.

## Funcionalidades
- Portada de album elegante
- Galeria en grid de fotos
- Vista de detalle con caption
- Modo slideshow automatico
- Diseno oscuro y elegante
- Responsivo

## Ejecutar

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Personalizar

1. Colocar fotos en `public/photos/`
2. Editar `src/data/albumItems.ts` para actualizar:
   - Rutas de fotos
   - Titulos y captions
   - Fechas

## Deploy en Vercel
- Root Directory: `apps/album-romantico`
- Framework: Vite
- Build Command: `npm run build`
- Output: `dist`
