# open-when

Coleccion de cartas digitales "abre cuando..." para distintos momentos emocionales.

## Funcionalidades
- Grid de tarjetas con diferentes situaciones
- Al tocar una tarjeta, se abre la carta completa
- Texto que aparece con animacion progresiva
- Diseno minimalista y emocional
- Responsivo para movil

## Ejecutar

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Personalizar

Editar `src/data/openWhenData.ts` para cambiar:
- Titulos de las cartas
- Contenido de cada carta
- Emojis y colores

## Deploy en Vercel
- Root Directory: `apps/open-when`
- Framework: Vite
- Build Command: `npm run build`
- Output: `dist`
