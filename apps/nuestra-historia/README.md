# nuestra-historia

Timeline romantico con la historia de la relacion.

## Funcionalidades
- Portada hero con titulo y subtitulo
- Contador de dias y meses juntos
- Linea del tiempo con eventos importantes
- Mensaje final romantico
- Diseno responsivo

## Ejecutar

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Personalizar

Editar los archivos en `src/data/` para cambiar:
- Fecha de inicio de la relacion
- Eventos del timeline
- Fotos (colocar en `public/photos/`)

## Deploy en Vercel
- Root Directory: `apps/nuestra-historia`
- Framework: Vite
- Build Command: `npm run build`
- Output: `dist`
