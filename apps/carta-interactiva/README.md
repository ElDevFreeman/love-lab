# carta-interactiva

Carta digital romantica con animacion de sobre interactivo.

## Funcionalidades
- Sobre animado que se abre al hacer clic
- Carta con texto que aparece progresivamente
- Boton de sorpresa final
- Musica de fondo opcional

## Ejecutar

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy en Vercel
- Root Directory: `apps/carta-interactiva`
- Framework: Vite
- Build Command: `npm run build`
- Output: `dist`
