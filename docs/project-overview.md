# Project Overview

## Que es love-lab

`love-lab` es un monorepo que contiene multiples proyectos romanticos digitales. Cada proyecto es un regalo interactivo pensado para sorprender y emocionar.

## Filosofia

- Simplicidad: cada app usa TypeScript + HTML + CSS + Vite
- Independencia: cada app compila y se despliega sola
- Estetica: el diseno debe ser elegante, emocional y cuidado
- Facilidad: cualquier app se puede publicar en minutos en Vercel

## Apps incluidas

### 1. carta-interactiva
Carta digital con animacion de sobre que se abre, texto progresivo y boton sorpresa.

### 2. nuestra-historia
Timeline romantico con portada, contador de dias juntos, eventos importantes y mensaje final.

### 3. frasco-de-mensajes
Frasco digital con mensajes aleatorios organizados por categorias (razones de amor, animos, recuerdos).

### 4. open-when
Coleccion de cartas "abre cuando..." para distintos momentos emocionales.

### 5. album-romantico
Album visual con galeria de fotos, descripciones y modo slideshow.

## Stack tecnologico

| Tecnologia | Uso |
|------------|-----|
| TypeScript | Logica y tipado |
| HTML5 | Estructura |
| CSS3 | Estilos y animaciones |
| Vite | Bundler y dev server |
| Vercel | Hosting y deploy |

## Orden recomendado de desarrollo

1. carta-interactiva (mas sencilla, valida el flujo)
2. frasco-de-mensajes (interaccion simple y divertida)
3. nuestra-historia (mas contenido, timeline)
4. open-when (multiples cartas)
5. album-romantico (galeria, slideshow)
